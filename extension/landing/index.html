FAQ

Frequently Asked Questions

Is MapLeads Pro free?

Yes! The core extension is completely free. You can scrape up to 100 leads per session and export to CSV at no cost. Pro and Enterprise plans unlock higher limits and more features.

Does it work on all Google Maps searches?

Yes — it works on any Google Maps business search, worldwide. Search for any niche + location and the extension will scrape all visible results.

Do I need to create an account?

No. Install the Chrome extension and start scraping immediately. No signup, no API keys, no credit card.

How fast does it scrape?

For basic fields (Name, Rating, Category, Address) it takes ~80ms per lead — 100 leads in under 10 seconds. For phone and website (requires clicking each card) it takes ~1.5 seconds per lead.

Where does my data go?

All scraped data stays 100% in your browser. Nothing is sent to any external server. Your leads are private and belong only to you.

Can I export to Google Sheets?

Yes — export as CSV, then import into Google Sheets via File → Import. You can also open the CSV directly in Excel or Numbers.

Will it work if Google updates their Maps UI?

Google occasionally changes their Maps DOM structure. When this happens, we update the extension selectors and push a new version. You'll get the update automatically through Chrome.
