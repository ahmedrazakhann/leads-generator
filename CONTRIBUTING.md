# Contributing to SaaSquatch Intelligence

Thank you for your interest in contributing to SaaSquatch Intelligence! We welcome contributions that help make this tool more powerful and accessible for sales teams.

## Code of Conduct

By participating in this project, you agree to maintain a professional and respectful environment.

## How Can I Contribute?

### Reporting Bugs
- Use the GitHub Issues tracker.
- Provide a clear description of the bug and steps to reproduce.
- Include environment details (Browser version, OS, etc.).

### Suggesting Enhancements
- Open a GitHub Issue with the tag `enhancement`.
- Describe the feature and the business value it provides.

### Pull Requests
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add some amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

## Development Workflow

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Chrome Extension
- Make changes in the `extension/` directory.
- Refresh the extension in `chrome://extensions/` to see changes.

## Code Style
- We use **Prettier** for code formatting.
- Ensure your code passes the existing **ESLint** rules in the `frontend` directory.
